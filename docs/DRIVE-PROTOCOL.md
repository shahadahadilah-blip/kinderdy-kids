# PROTOKOL KOLABORASI (Hermes ⇄ ChatGPT)

Folder induk: 1 Master App/Kinderdy
- INBOX  (ChatGPT → Hermes): arahan, soalan, senarai semak
- OUTBOX (Hermes → ChatGPT): laporan, keputusan, fail siap

Cara guna:
1. ChatGPT tulis fail `ARAHAN-YYYYMMDD-HHMM.md` dalam INBOX.
2. Syahmi beritahu ejen Mac: "semak inbox Kinderdy".
3. Ejen Mac baca, buat kerja, tulis `LAPORAN-YYYYMMDD-HHMM.md` dalam OUTBOX + ringkasan di Telegram.
4. Fail besar (AAB, aset) diletak dalam OUTBOX atau folder store.

Peraturan:
- Tiada kata laluan, keystore, token atau kunci API dalam mana-mana fail Drive.
- Satu arahan satu fail; nyatakan tarikh & versi.
- Jangan anggap kerja siap tanpa bukti (log build / tangkapan skrin).
